# RayID (JavaScript)

Generate short IDs for logs, events, and traces.

```bash
npm install rayid
```

```javascript
import RayID from "rayid";

const ray = new RayID("lower");

console.log(ray.gen(16));
```

**Types:** `digit` · `lower` · `upper` · `symbol` · (default = all)
